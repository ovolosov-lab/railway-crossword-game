# ADR 0011: Умеренная частота двухбуквенных слов

- **Статус:** реализовано в задаче 46
- **Дата:** 2026-11-27
- **Область:** оценка вариантов продольного заполнения и частота двухбуквенных слов в маршруте игровой сессии
- **Связанные решения:** [ADR 0007 — непрерывная игра и генерация слов](./0007-continuous-game-player-sessions.md), [ADR 0010 — необязательные пересечения](./0010-game-crossword-version.md), [задача 37 — улучшение генератора](../tasks_backlog.md)

## Контекст

ADR 0007 установил цель сократить частоту однобуквенных и двухбуквенных слов, сохранив случайные варианты «оставить», «заменить» и «оставить место пустым». В задаче 37 выбор лучшего из шести раскладок стал минимизировать общее количество слов обоих коротких размеров.

На историческом воспроизводимом сравнении для английского словаря задачи 33, 46 участков карты и 30 seed доля двухбуквенных слов составила 8,39% у MVP, 3,31% при одной попытке нового алгоритма и 0% при выборе лучшей из шести попыток. В 80 игровых сессиях владелец проекта также не встретил двухбуквенных слов. Текущее ранжирование, таким образом, практически устранило их, хотя целью было уменьшить частоту, а не исключить такие слова.

## Решение

1. Для каждого нового, ещё не опубликованного сегмента генератор один раз выбирает режим оценки двухбуквенных слов: штраф включён с вероятностью 50% и выключен с вероятностью 50%. Выбор выполняется через тот же переданный генератор случайных чисел, что и остальные случайные решения.
2. Выбранный режим применяется одинаково ко всему набору из шести вариантов этого сегмента. Режим не выбирается отдельно для каждой попытки: иначе лучший из шести вариантов почти всегда мог бы оказаться из попытки без штрафа.
3. Однобуквенные слова остаются под постоянным штрафом. В порядке оценки вариантов сохраняются текущие приоритеты достижения цели по свободному месту и уменьшения однобуквенных слов; при включённом режиме следующим критерием минимизируется количество двухбуквенных слов. При выключенном режиме их количество не участвует в сравнении вариантов.
4. Размер слова для этой оценки определяется количеством букв (`WordCandidate.letters`), как в текущем генераторе; число клеток (`WordCandidate.cells`) по-прежнему отдельно определяет физическую длину размещения.
5. Действия `KEEP`, `LONGER` и `EMPTY`, правила размещения поперечных слов длиной 3–7 из ADR 0010 и подсчёт очков за каждое слово не меняются.
6. Режим выбирается при первой генерации сегмента. Выбранная раскладка публикуется и остаётся общей для участников, повторно использующих этот сегмент.
7. Перед генерацией новых сегментов для выбранного маршрута подсчитываются двухбуквенные слова во всех уже опубликованных сегментах этого маршрута. Затем для каждого нового сегмента подсчёт дополняется словами из выбранной раскладки. Если до начала нового сегмента счётчик уже больше нуля, двухбуквенные кандидаты исключаются из всех шести вариантов этого сегмента независимо от режима штрафа. Они не заменяются короткими словами; оставшееся место распределяется между другими словами текущей функцией размещения. Правило начинает действовать со следующего сегмента: оно не ограничивает число двухбуквенных слов внутри текущей раскладки.
8. Уже опубликованные сегменты остаются неизменными. Если они уже содержат несколько двухбуквенных слов, счётчик учитывает их все; правило не является жёсткой квотой для полной сессии.

Вероятность 50% относится только к включению штрафного режима для сегмента. Она не означает, что двухбуквенное слово появится ровно в половине сегментов или игровых сессий.

## Проверка частоты

Для сопоставимости повторяется benchmark задачи 37: английский каталог задачи 33 (647 слов), все 46 участков из `routes.json`, 30 прежних фиксированных seed и шесть вариантов на сегмент. Проверка собирает:

- долю размещённых слов, содержащих ровно две буквы;
- долю сегментов, где появилось хотя бы одно такое слово;
- долю однобуквенных слов;
- долю раскладок, достигших цели по свободному месту;
- частоту включения штрафного режима и воспроизводимость результата при повторе seed.

Этот benchmark изолирует влияние 50/50 режима ADR 0011 и рассматривает участки как независимые варианты генерации. Подавление двухбуквенных слов на последующих сегментах проверяется отдельно на последовательностях новых и ранее опубликованных сегментов одного маршрута.

Целевой диапазон для доли двухбуквенных слов в основном benchmark — **от 1% до 5%**. Он должен заметно отличаться от 0% текущего режима с шестью попытками и оставаться ниже 8,39% исторического MVP. Доля однобуквенных слов не должна превысить исторический результат нового алгоритма с шестью попытками — 0,02%; цель по свободному месту должна достигаться не менее чем в 95% раскладок.

Дополнительно benchmark запускается на текущих русских и английских словарях с теми же маршрутами и seed; результаты и доля сегментов с двухбуквенными словами фиксируются отдельно по языкам. Тесты также проверяют оба режима, применение одного режима ко всем шести попыткам и детерминированность при фиксированном seed.

Если основная выборка не попадает в целевой диапазон, долю режима штрафа нельзя объявлять равной доле появившихся слов. Параметр или функция оценки пересматриваются по измеренным результатам отдельным изменением решения.

### Результаты реализации

Проверка задачи 46 повторно выполнена после разделения базового и поперечного пулов в задаче 47: 46 участков и 30 фиксированных seed. Для исторического английского каталога из 647 слов доля двухбуквенных слов составила **3,16%** (прежний MVP — 8,39%), доля сегментов хотя бы с одним таким словом — **8,26%**, однобуквенных слов — **0%**. Штрафный режим выбран для **49,28%** сегментов; цель по свободному месту достигнута в **100%** раскладок.

На текущих каталогах, загруженных из файлов миграций, получены отдельные показатели:

| Набор | Слов в каталоге | Двухбуквенные слова | Сегменты хотя бы с одним двухбуквенным словом | Однобуквенные слова | Цель по свободному месту |
|---|---:|---:|---:|---:|---:|
| `ru` | 3551 | 3,90% | 12,03% | 0% | 100% |
| `en` | 1871 | 3,11% | 8,84% | 0% | 100% |

Предел 0,02% для однобуквенных слов соблюдён в основном историческом наборе и в обоих дополнительных языковых прогонах.

Проверки также подтвердили одинаковый режим штрафа для всех шести вариантов сегмента и воспроизводимость слов и координат при повторе seed.

## Последствия

- Двухбуквенные слова могут появляться снова, но их частота контролируется на уровне оценки вариантов и проверяется против исторического MVP.
- После появления двухбуквенного слова в уже опубликованной или ранее сгенерированной части маршрута новые сегменты не добавляют такие слова; оставшаяся длина распределяется равномерно между выбранными словами.
- Однобуквенные слова остаются под прежним постоянным приоритетом сокращения.
- Случайное решение полностью воспроизводимо при том же `random.Random` seed; оно не меняется между игроками после публикации общего сегмента.
- Из-за неизменности общих сегментов и возможной конкурентной первой публикации число двухбуквенных слов во всей сессии может быть больше одного; правило запрещает их добавление только в последующие ещё не опубликованные сегменты.
- Для нового режима не нужны изменения API, схемы PostgreSQL или Redis-формата опубликованного размещения.

## Вне объёма

- Гарантия, что каждое игровое поле или каждый маршрут содержит двухбуквенное слово.
- Перестройка уже опубликованных общих сегментов ради соблюдения квоты двухбуквенных слов.
- Изменение словаря, правил пересечения, действий `KEEP`/`LONGER`/`EMPTY` или начисления очков.
